This directory contains frozen measurement inputs for offline scoring.

`classification/` contains window and paper IDs, labels, saved probabilities and thresholds, and paper-level split membership. Evaluation uses L1–L4: physical hardware, commercial cloud, public/shared HPC, and hosted models/API services. The teacher evaluation contains 2,472 windows; the BERT-base, RoBERTa-base and SciBERT evaluations each contain 4,658 windows. The release reproduces the per-label counts, micro precision/recall/F1 and macro F1 from each model's saved predictions.

`gpu/` contains 2,698 entity-annotated gold records and saved extraction predictions for both thinking settings. Gold records retain GPU/count entity strings and span positions. Scoring covers resource detection, normalized and strict GPU model matching, quantities, and normalized and strict model/count pairs. The hardware catalog is exported as CSV with its specification source links. Normalization mappings, review dispositions, VRAM overrides and deterministic configuration selection rules accompany the catalog. The performance supplement contains 132 unique model names and generation-level donor statistics; donors are originally observed models with positive performance, averaged equally within the exact generation before logarithmic transformation.

`ksc/` contains the formal frozen focal mapping, topic-year aggregates and threshold availability tables. KSC uses 768-dimensional SPECTER vectors with the contract in `configs/measurement/ksc/run_contract.json`. Offline checks verify topic windows, focal self-exclusion arithmetic, missingness and the 50/100/200 historical-paper thresholds. The release has 29,591 focal mappings, 2,167 topic-year cells and 731 primary topics.

Run the repository's reproduction command to write measurement tables under the selected output directory. `measurement.run_measurement(repo_root, output_dir)` provides the same operation as a Python interface. Frozen comparison metrics are in `results/reference/measurement/`; file-level sources, projections and hashes are recorded in `code/measurement/asset_sources.json`. Model metadata records the selected SciBERT weights hash and size.
