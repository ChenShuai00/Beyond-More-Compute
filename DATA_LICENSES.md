# Data and source attribution

The repository's derived research tables, annotation labels and analysis outputs are provided under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Cite “Beyond More Compute contributors, Beyond More Compute replication materials, version 1.0.0 (2026).” The code and documentation use the MIT license in `LICENSE`.

OpenAlex metadata use [CC0](https://github.com/ourresearch/openalex-docs/blob/main/license.md). Retained OpenAlex Work and Topic IDs identify the underlying records. Frozen citation measurements use the 12 September 2026 collection snapshot.

Hardware facts retain vendor/specification source URLs in `data/measurement/gpu/hardware_specifications.csv`. The classification examples retain their scholarly source identifiers and third-party links. Third-party documents and dependencies retain their respective terms.

Figure audit utilities in `code/figures/qa_tools/` were adapted from the local `nature-figure` tooling; `code/figures/asset_sources.json` records the copied source hashes. The numerical estimation kernel was adapted from the research analysis workspace; source lineage is recorded in the manifests.
